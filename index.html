About Smart Complaint Portal

Smart Complaint Portal is a web-based application designed to help citizens report and track community-related problems such as sanitation, water supply, garbage collection, road problems and electricity issues.

The application uses HTML, CSS and JavaScript. Complaint information is stored locally in the browser using LocalStorage.
